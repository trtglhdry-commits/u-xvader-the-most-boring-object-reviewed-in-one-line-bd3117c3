## The entry

> The dustpan: gathers everything you sweep toward it, then leaves one thin line of dirt behind, every single time.

## How it works

`main.ts` (Node 22, stdlib only) writes the single review line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic — no randomness, no network, no clock — with a runtime guard enforcing the 1–200 character, single-line gate.
